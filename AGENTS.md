# Pipeline Gurus design instructions

This repository is the source of truth for Pipeline Gurus visual work.

Before creating UI, social artwork, a deck, or a report:

1. Read `DESIGN.md` in full.
2. Use exact values from `tokens/tokens.css` or `tokens/tokens.json`.
3. Inspect `preview/index.html` for the intended hierarchy and composition.
4. Use `assets/pipeline-gurus-logo.jpg`; never invent or redraw the logo.

Hard rules:

- Bebas Neue is for headlines. Poppins is for body copy and UI.
- Use black, white, and `#F6283F`. Red is one spark per frame, never body text.
- Keep 40–50% empty space and one visual hero.
- Use rectangular, angled geometry. Avoid circles, rounded cards, gradients, glass, and decorative 3D.
- Prefer a Z-pattern or left-weighted layout. Do not center every element.
- One logo and no more than one CTA per frame.
- Use monochrome photography with a 20–30% black overlay when text needs contrast.
- Write confident, specific, data-driven copy. No emojis or motivational filler.

If a new visual decision is not covered, stay sharp, flat, high-contrast, and restrained. Ask before adding a color, font, radius, or logo treatment.
