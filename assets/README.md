# Brand assets

`pipeline-gurus-logo.jpg` is the official white-on-black horizontal logo extracted unchanged from `PG Social Media Guidelines.xlsx`.

Keep the full rectangular lockup intact. Do not trace, recolor, distort, rotate, crop, or add effects. The source guidelines refer to horizontal, vertical, and icon-only variants in multiple colors, but those files were not supplied separately. Request approved originals before using those variants.
